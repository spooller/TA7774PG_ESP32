# TA7774PG_ESP32
Library for controlling Toshiba TA7774PG/TB6674PG stepper motor drivers with ESP32.

## Features
- Position control (0-100%)
- Calibration support (endstops)
- Power management (VS2B standby)
- Overcurrent/thermal protection (for TB6674PG)

## Installation
1. Download the ZIP and install via Arduino IDE:  
   **Sketch → Include Library → Add .ZIP Library**  
2. Or clone into your Arduino libraries folder:
   ```bash
   git clone https://github.com/spooller/lib/TA7774PG_ESP32.git
